# by-framework

Reverse lookup: given a framework name, what parts (matrices, indices, libraries) in this repo
belong to it. Not yet exhaustive over every framework dual-order-os intends to serve — populated
so far for the frameworks that have contributed real content.

## LHEA (topology)

The-unicorn-estate's `topology/*.md` drafts (see `indices/by-source-document/README.md`) are
LHEA material. They feed:

- `matrices/latin-roots/` — the 275-root inventory
- `matrices/hebrew-glyphs/` — all 22 glyphs, pictograph + gematria + proposed execution role
- `indices/by-glyph/` — all three unreconciled root-glyph assemblies

## Lhea-Tema (kernel)

`AGI144348Outlook/Lhea-Tema`'s `lhea-tema-kernel.js` is the source for several rows in
`matrices/algorithms/algorithms.json`:

- `eba-memory-shedding-damping-ejection` — EBA eigenvalue-based memory regulation
- `isa-triplet-execution-pipeline` — the kernel's 7-phase (root, glyph, icon) execution pipeline
- `root-myelination-hardening` — root hardening into a CORE_NODE
- `ocean-circulation-cave-precipitation` — the OCEAN→CAVE memory migration
- `jurisdiction-emergence-detection` — coherence-based jurisdiction recognition

## echo-prototype (five-tick engine)

`AGI144348Outlook/echo-prototype`'s `src/runtime/five-tick-engine.js` contributes:

- `five-tick-causal-wave-pipeline` — the 5-tick symbolic execution pipeline
- `supernova-compiler-reconciliation` — the jurisdiction permits/forbids check it calls

## eve3 / MashetEVE (lexicon_eve)

`libraries/eve/` in this repo (built for the `english-lexicon-eve` matrix, generalizing eve3's
technique for the 22 Hebrew letters) contributes:

- `golden-angle-sphere-placement`, `eve-angular-nearest-neighbor-lookup`,
  `category-tightness-clustering-metric` (`lexicon_eve.py`)
- `bidirectional-glyph-root-index` (`bidirectional_glyph_index.py`)
- `by-is-a-taxonomic-index-builder`, `deepest-common-ancestor-finder` (`by_is_a_index.py`)
- `wordnet-greedy-nn-ordering` (`discovers_meaning_test.py`)

All of the above are cataloged as rows in `matrices/algorithms/algorithms.json` — see that
matrix's README for the full table and the one additional design-draft row
(`sequential-agency-dispatcher`) that belongs to no existing framework yet.

## Mashet

`matrices/mashet-dictionary/` and `libraries/eve/generator/mashet_code_generator.py` are Mashet
material, already documented in their own READMEs — not duplicated here.

## Everything else

JurisDictionary and "whatever comes next" (per the root README) have no dedicated rows here yet
— this index grows as those frameworks contribute real, committed content.
