# Topology v2 — Curated Shared-Root Set (60 Roots)

**Assembly, not canon.** One of three unreconciled root-glyph assemblies over the same
underlying matrices — see `../README.md` for why all three are kept side by side. This file
transcribes `the-unicorn-estate/topology/02-glyph-topology-v2-shared-roots.md`, the revision
that corrects v1's forced-even distribution: **60 unique roots total**, profile sizes ranging
naturally from 2 to 4 roots per glyph, and — the key addition — **8 roots explicitly shared
across 2–3 glyphs**: `cap-`, `circ-`, `man-`, `port-`, `prim-`, `reg-`, `sep-`, `spec-`
(14 profile slots from those 8 alone; the remaining 52 roots belong to exactly one glyph).

As with v1, root identifiers use classical stem form (`cap-`, not a dictionary-word row) and do
not literally join against `matrices/latin-roots/roots.json`, which is keyed off the different,
later 275-root source document. Glyph names match `matrices/hebrew-glyphs/glyphs.json` exactly.

— this specific point (Resh as hub) is still unresolved.
