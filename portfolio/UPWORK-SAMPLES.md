# Portfolio descriptions to adapt for Upwork

These are descriptions of independent AI-assisted projects. No clients, revenue, deployment guarantees or unaided authorship are implied.

## Versioned knowledge catalog

**Role:** Product direction and AI-assisted prototype development.

**Description:** Developed a reusable reference-catalog prototype with stable records, revision history, templates and independent project configurations. The demonstration edits one project while preserving another and its historical references, then reopens SQLite to show persistence. AI assisted implementation and verification.

**Suggested skills:** Python, SQLite, data organization, workflow design.

**Media:** 60-second catalog recording and a screenshot of the output. [Runbook](demos/catalog/README.md).

## Persona-session filtering

**Role:** Workflow definition and AI-assisted data-processing prototype development.

**Description:** Designed a conversation-review workflow separating ordinary name mentions from candidate persona sessions. This synthetic demonstration runs an existing deterministic filter and shows direct address, subsequent continuation and a switch to another persona. Results retain source references and require human review before use as memory.

**Suggested skills:** JavaScript, JSON processing, data workflows, requirements analysis.

**Media:** Two retained synthetic prompt/reply pairs plus the source fixture. [Runbook](demos/persona-filter/README.md).

## Persistent shared workspace

**Role:** Product direction and AI-assisted application prototyping.

**Description:** A shared workspace prototype with movable widgets, quizzes, persistence and scoped agent tools. A small offline recording demonstrates widget creation and restoration after reload. Automated checks cover command validation, permissions and SQLite behavior. Offline scripted actions are distinguished from optional live-model integrations.

**Suggested skills:** JavaScript, SQLite, web applications, API integration, prototyping.

**Media:** Offline create/move/reload recording. [Runbook](case-studies/shared-workspace.md).

## Narrow first service

“I will turn one clearly defined workflow into a small working prototype, with sample data, setup instructions and an acceptance walkthrough.”

Agree one input, one output, supported formats, failure behavior, revision allowance and handoff. Quote hosting/API costs separately. Avoid promising n8n, Make or Zapier expertise until demonstrated in those tools; custom JavaScript/Python workflow work is the evidence currently shown.
