# Upwork work and pricing context

Checked 23 October 2026. USD, gross billing. Search-index excerpts were available; several direct Upwork page opens returned HTTP 403. Posted budgets can be placeholders, change or refer only to an initial milestone. These examples are not a random sample, a verified earnings dataset, or confirmation a vacancy remains open.

## What clients buy

**AI automation:** route enquiries to a CRM, classify messages, extract fields from documents, prepare draft replies for review, update spreadsheets, produce recurring reports, connect APIs/webhooks, repair existing workflows, or build a knowledge-base assistant. Common platforms include n8n, Make, Zapier, CRMs, messaging services and custom code.

**MVP work:** create the smallest usable version of a product: a few screens, one core workflow, persistence and an API integration. Some listings also require authentication, billing, deployment, monitoring and support, making them much larger than a visual demo. A working prototype and a production-ready subscription platform have different acceptance criteria.

Timothy's nearest fit is bounded custom-code knowledge/data workflows and small prototypes. The reviewed repositories do not demonstrate n8n/Make/Zapier competence specifically.

## Suggested initial pricing experiment for Timothy

Recommendation, not observed earnings: test **$25–$35/hour** on narrowly scoped work that matches the demonstrations, or **$150–$350** for a small fixed deliverable after estimating actual effort. Example: one JSON export format, deterministic extraction rules, a reviewable output file and a short handoff. A small **$500–$1,000** prototype milestone can be considered only with an explicit feature list and effort estimate; this is not a quote for a complete SaaS product.

Do not underprice an open-ended “build my AI business” request. Define revisions, client responsibilities, credentials, data access and support separately. Increase rates when delivery evidence and demand support it.

Upwork's freelancer service fee is currently **0–15% per contract**, disclosed before acceptance. At a $30/hour gross rate that leaves $25.50–$30 before taxes and other costs, depending on the contract fee. Proposal costs, unpaid discovery, support and idle time further affect effective earnings. For a fixed $300 contract, six hours is $50/hour gross; twenty hours is $15/hour gross.
