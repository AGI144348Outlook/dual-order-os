# design-notes

Architectural design rationale that governs how future frameworks in this repo are built, but
that doesn't belong inside any single matrix, index, or library — the reasoning behind a rule,
not the rule's data.

## Contents

- `heavens-earth-duality.md` — adopted principle (grounded in the Hebrew morphology of
  Genesis 1:1) that a coordinate/addressing space is defined complete and unchanging from the
  start, while only its *occupancy* — which NVE sits where, what content a matrix row holds —
  starts empty and is populated progressively. Applies to any future EVE built on this
  repo's infrastructure.
