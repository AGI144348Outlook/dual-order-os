# libraries

Importable Python code built from `/matrices` and `/indices`, once they're populated.

No longer entirely empty: `eve/` holds working modules for the shelves that already have data
— bidirectional glyph indexing, the `by-is-a` taxonomy index and its discovers-meaning test,
the `LexiconalEVE` lexicon/lookup implementation, a Mashet-dictionary entry generator
(`eve/generator/`), and a word-sense-disambiguation toolkit (`eve/wsd/`). See `eve/`'s own
files and the READMEs under `/matrices` and `/indices` for what each module backs.

Every other framework's library code is still reserved shelf space, added once that
framework's matrices/indices are populated.
