# Libraries

Reusable components developed on the integration branch:

- [Mapped algorithm combinations](algorithms/mapped-combinations/README.md): 14 combinations, code references, status and explicit recipes.
- [Sentence cards](echo_sentence_cards.py): sense-specific vocabulary and versioned sentence positions.
- [Catalog box](catalog_box.py): persistent identities, templates and configurations.
- [Echo workspace](echo_workspace.py): preserved Genesis with typed links and queries.
- [Language interface](echo_language.py): bounded parsing, auditing and articulation.

Existing EVE libraries remain under [eve/](eve/). These modules do not form an autonomous dispatcher.
